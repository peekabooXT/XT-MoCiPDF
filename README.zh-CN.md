**1.14.0** — 备注：直接在 PDF 页面输入，Ctrl+Enter 保存，Esc 取消；拖住备注可移动，双击可编辑。顶部计时器支持开始、暂停与重置，关闭后保存时长，再次启动时暂停。所有导出方式（包括多文件合并）都在右下角「导出…」中，Ctrl+E 打开菜单。词典可勾选「隐藏释义」，点击查看当前释义，换词后自动重新遮盖；隐藏偏好会保存。

XT (XuTao) 的桌面工具，用于阅读英文 PDF、收集词汇和做研究笔记。读过一页，留下痕迹。

## 安装并启动

从 [Releases](https://github.com/peekabooXT/XT-ReadTrace/releases) 下载 XT-ReadTrace-1.14.0-Setup-x64.exe，然后运行安装程序。它包括完整的离线词典、英文OCR数据和运行时间。保持桌面快捷方式选项处于启用状态。已安装的应用程序不需要安装 Python 或帐户。

默认安装文件夹是`D:\tools\codex\XT-ReadTrace`。打开名为 XT 阅迹 的桌面快捷方式，或运行 `XT阅迹.exe`。将 `_internal` 和 `dictionary` 文件夹与可执行文件放在一起。

## 界面语言

默认为英语。打开设置，选择界面语言，然后保存。界面立即切换并记住您的选择以供将来启动。可用语言：中文、英语、德语、日语、法语、韩语、意大利语、印地语、西班牙语、现代标准阿拉伯语、葡萄牙语和俄语。阿拉伯语使用从右到左的界面。

语言选择适用于阅读工具、设置、对话框、导出选项、帮助、状态消息和错误。它不会翻译原始 PDF、收集的英语术语或您的个人定义。捆绑词典提供英汉释义。包含日语、韩语、阿拉伯语和印地语的所有语言资源和开放许可 Noto 字体，可供离线使用。

## 阅读、收集和注释

1. 导入一份或多份英文 PDF，或将它们拖到窗口中。支持文本 PDF 和扫描 PDF。
2. 双击某个单词即可收集；再次双击其彩色粗体下划线可删除该事件。单击或拖动以选择一个短语，检查下面的文本，然后按 Enter 将其收集。
3. 连续滚动页面。选择连续的单页或两页视图、调整缩放、跳转到页面或搜索 PDF。
4. 使用突出显示文本、下划线文本、手绘笔、矩形或文本注释来阅读注释。注释直接出现在页面上，支持多行，并且可以在选择/阅读模式下双击进行编辑。使用橡皮擦、注释管理器、撤消或重做来修改注释。
5. 七个工具快捷方式默认为 1-7，可以在“设置”中更改。当您在可编辑字段中键入内容时，快捷方式不会切换工具。

对于扫描，请先在当前页面上运行 OCR。该应用程序使用捆绑的英文 OCR 数据。检查识别结果，特别是在复杂的列、表格、公式或低质量扫描中。

## 离线词典和个人含义

所包含的 ECDICT 词典包含 770,611 个条目。选择一个单词或输入查询以查看其含义、发音和可能的基本形式。如果缺少短语，应用程序会清楚地标记其组成词定义。

使用编辑/添加含义来保存您自己的解释和可选发音。个人含义在 PDF 之间共享，重新启动后仍可保存，并在查找和词汇表导出中优先。捆绑的词典保持只读状态。恢复字典含义需要确认。

## 导出一份 PDF 或合并多本单词书

- 单词本TXT：导出兼容MAiMemo的云单词本的UTF-8文本。章节模式每行保留一个完整的单词或短语并保留大小写。还提供页面章节、纯文本和 `//` 基本形式模式。基本形式处理由MAiMemo执行。
- 多个 PDF：单击「导出…」菜单中的合并单词书，检查文件并预览结果。根据需要选择全部或清除选择。删除文件中的重复项，可选择转换为小写，并导出单个 TXT 单词簿。 TXT 可以按文件、按文件和页面或将条目分组到一章中。
- 可打印词汇表：导出 A4 PDF，左侧为英语单词或短语，右侧为含义。预览和编辑此导出的含义。长的含义通过重复的列标题延续到后续页面。合并表可以包含所有选中的 PDF，并使用您保存的个人含义。
- 单词和注释 PDF：创建包含收集的单词样式和标准 PDF 注释的副本。文本注释仍然直接可见且可打印。原始 PDF 被保留。
- 阅读带有书写空间的 PDF：在可视文本行之间添加一到两个空行以用于手写笔记。选择所有页面、当前页面或页面范围。输出使用 A4 分页，并且可以包括收集的单词样式。处理在后台运行并且可以取消。

合并读取选定的记录，而不更改其 PDF、标记、注释或您的阅读位置。单词本包含收集的术语；阅读重点和其他注释会在带注释的 PDF 中单独导出。

## 个人数据和升级

该应用程序将您的 PDF、词汇、笔记、偏好和个人含义存储在其本地 `data` 文件夹中。导出的文件通常保存在`exports`中。移动到另一台计算机时，关闭应用程序并备份这两个文件夹。

安装程序升级会保留现有的个人数据。卸载会删除程序文件和快捷方式，同时保留个人数据。源版本和初始安装程序不包括个人 PDF、图书馆记录、密码和导出文件。 PDF 打开密码保存在内存中，不会保存到磁盘。

## 从源代码运行

使用独立的 CPython 3.12 或更高版本。建议使用隔离环境以避免 Qt DLL 与 Anaconda 发生冲突。安装 Python 依赖项可能需要访问互联网；该词典是捆绑的，可以离线准备。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\src\requirements.txt
.\src\prepare_dictionary.ps1 -Python .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe .\src\app.py
```

`dictionary/ecdict.sqlite.gz` 包含完整的字典。准备脚本验证校验和并在本地解压缩。 Windows 安装程序包括解压的数据库。字典源和校验和信息在`dictionary/source.json`中；它的 MIT 许可证是 `dictionary/LICENSE.txt`。

## 构建并验证

```powershell
.\src\build.ps1 -Python python
.\tests\run_checks.ps1 -Python .\.venv\Scripts\python.exe
.\installer\build-installer.ps1 -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -Payload 'path-to-complete-payload'
```

使用 Inno Setup 6.7 或更高版本构建。测试使用生成的样本和隔离的临时库。它们涵盖阅读、选择、连续页面、OCR、词典、注释、导出、多文件合并和语言首选项。安装程序有效负载包括语言目录，但不包括 `data`、`exports`、`.git` 和测试工件。
