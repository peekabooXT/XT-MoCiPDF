**1.14.0** — PDF上で直接メモを入力し、Ctrl+Enterで保存、Escでキャンセルします。保存したメモはドラッグで移動、ダブルクリックで編集できます。上部のタイマーは開始・一時停止・リセットに対応し、再起動後は保存した時間で停止します。複数ファイルの結合を含むすべての出力は、右下のエクスポート（Ctrl+E）から選択できます。辞書の意味を隠し、必要なときだけ表示できます。次の検索では再び隠れ、設定は保存されます。

英語の PDF を読んだり、語彙を収集したり、研究ノートを作成したりするための XT (XuTao) のデスクトップ ツール。ページを読んで、足跡を残しましょう。

## インストールして起動する

[Releases](https://github.com/peekabooXT/XT-ReadTrace/releases) から XT-ReadTrace-1.14.0-Setup-x64.exe をダウンロードし、インストーラーを実行します。これには、完全なオフライン辞書、英語 OCR データ、およびランタイムが含まれています。デスクトップ ショートカット オプションを有効のままにしておきます。インストールされたアプリには、Python のインストールやアカウントは必要ありません。

デフォルトのインストールフォルダーは `D:\tools\codex\XT-ReadTrace` です。 XT 阅迹 という名前のデスクトップ ショートカットを開くか、`XT阅迹.exe` を実行します。 `_internal` フォルダーと `dictionary` フォルダーを実行可能ファイルの横に保管します。

## インターフェース言語

英語がデフォルトです。 「設定」を開き、「インターフェース言語」を選択して保存します。インターフェイスはすぐに切り替わり、将来の起動のために選択を記憶します。利用可能な言語: 中国語、英語、ドイツ語、日本語、フランス語、韓国語、イタリア語、ヒンディー語、スペイン語、現代標準アラビア語、ポルトガル語、ロシア語。アラビア語は右から左へのインターフェイスを使用します。

言語の選択は、読み取りツール、設定、ダイアログ、エクスポート オプション、ヘルプ、ステータス メッセージ、およびエラーに適用されます。オリジナルの PDF、集められた英語用語、または個人的な定義は翻訳されません。付属の辞書には英語と中国語の意味が記載されています。日本語、韓国語、アラビア語、ヒンディー語のすべての言語リソースとオープンライセンスの Noto フォントがオフラインで使用できるように含まれています。

## 読んで、収集して、注釈を付ける

1. 1 つ以上の英語 PDF をインポートするか、ウィンドウにドラッグします。テキスト PDF とスキャンされた PDF がサポートされています。
2. 単語をダブルクリックして収集します。色付きの太字の下線を再度ダブルクリックして、その箇所を削除します。クリックまたはドラッグしてフレーズを選択し、下のテキストを確認して、Enter キーを押して収集します。
3. ページ間を継続的にスクロールします。連続した 1 ページまたは 2 ページの表示を選択したり、ズームを調整したり、ページにジャンプしたり、PDF を検索したりできます。
4. 注釈を読むには、ハイライト テキスト、下線テキスト、フリーハンド ペン、四角形、またはテキスト ノートを使用します。メモはページ上に直接表示され、複数行をサポートし、選択/読み取りモードでダブルクリックすることで編集できます。注釈を修正するには、消しゴム、注釈マネージャー、元に戻す、またはやり直しを使用します。
5. 7 つのツール ショートカットはデフォルトで 1 ～ 7 であり、[設定] で変更できます。編集可能なフィールドに入力している間、ショートカットではツールが切り替わりません。

スキャンの場合は、まず現在のページで OCR を実行します。このアプリはバンドルされた英語の OCR データを使用します。特に複雑な列、表、数式、または低品質のスキャンでの認識結果を確認します。

## オフライン辞書と個人的な意味

付属の ECDICT 辞書には 770,611 のエントリが含まれています。単語を選択するかクエリを入力すると、その意味、発音、および考えられる基本形が表示されます。フレーズが欠落している場合、アプリはその構成要素である単語の定義に明確なラベルを付けます。

編集/意味の追加を使用して、独自の説明とオプションの発音を保存します。個人的な意味は PDF 間で共有され、再起動後も存続し、検索や語彙表のエクスポートで優先されます。バンドルされた辞書は読み取り専用のままです。辞書の意味を復元するには確認が必要です。

## 1 つの PDF をエクスポートするか、複数の単語帳を結合します

- Wordbook TXT: MAiMemo のクラウド単語帳と互換性のある UTF-8 テキストをエクスポートします。チャプター モードでは、1 行に 1 つの完全な単語またはフレーズが保持され、大文字と小文字が区別されます。ページチャプター、プレーンテキスト、および `//` 基本形式モードも利用できます。基本形式の処理は MAiMemo によって実行されます。
- 複数の PDF: エクスポートメニューにある [単語帳を結合] をクリックし、ファイルを確認し、結果をプレビューします。必要に応じてすべてを選択するか、選択を解除します。ファイル間で重複を削除し、必要に応じて小文字に変換し、単一の TXT 単語帳をエクスポートします。 TXT では、エントリをファイルごと、ファイルとページごと、または 1 つの章にグループ化できます。
- 印刷可能な語彙表: 左側に英語の単語またはフレーズ、右側に意味が記載された A4 PDF をエクスポートします。このエクスポートの意味をプレビューおよび編集します。長い意味は、列ヘッダーが繰り返されて後続のページに続きます。結合されたテーブルには、チェックされたすべての PDF を含めることができ、保存された個人的な意味が使用されます。
- 単語と注釈 PDF: 集められた単語のスタイルと標準の PDF 注釈を含むコピーを作成します。テキストメモはそのまま直接表示および印刷可能です。元の PDF は保存されます。
- 書き込みスペースのある PDF の読み取り: 手書きメモのビジュアル テキスト行の間に 1 行または 2 行の空白行を追加します。すべてのページ、現在のページ、またはページ範囲を選択します。出力は A4 ページネーションを使用し、収集された単語のスタイルを含めることができます。処理はバックグラウンドで実行され、キャンセルすることができます。

結合では、PDF、マーク、メモ、または読み取り位置を変更せずに、選択したレコードを読み取ります。単語帳には集められた用語が含まれています。読書ハイライトとその他の注釈は、注釈付き PDF として個別にエクスポートされます。

## 個人データとアップグレード

このアプリは、PDF、語彙、メモ、設定、個人的な意味をローカルの `data` フォルダーに保存します。エクスポートされたファイルは通常、`exports` に保存されます。別のコンピューターに移動する場合は、アプリを閉じて両方のフォルダーをバックアップします。

インストーラーのアップグレードでは、既存の個人データが保存されます。アンインストールすると、個人データは残されたまま、プログラム ファイルとショートカットが削除されます。ソース リリースと初期インストーラーには、個人用 PDF、ライブラリ レコード、パスワード、エクスポート ファイルは含まれません。 PDF を開くパスワードはメモリに保持され、ディスクには保存されません。

## ソースから実行

スタンドアロンの CPython 3.12 以降を使用します。 Qt DLL と Anaconda の競合を避けるために、分離された環境をお勧めします。 Python の依存関係をインストールするには、インターネット アクセスが必要になる場合があります。辞書はバンドルされており、オフラインで準備できます。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\src\requirements.txt
.\src\prepare_dictionary.ps1 -Python .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe .\src\app.py
```

`dictionary/ecdict.sqlite.gz` には完全な辞書が含まれています。準備スクリプトはチェックサムを検証し、ローカルで解凍します。 Windows インストーラーには、解凍されたデータベースが含まれています。辞書ソースとチェックサム情報は `dictionary/source.json` にあります。 MIT ライセンスは `dictionary/LICENSE.txt` にあります。

## 構築して検証する

```powershell
.\src\build.ps1 -Python python
.\tests\run_checks.ps1 -Python .\.venv\Scripts\python.exe
.\installer\build-installer.ps1 -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -Payload 'path-to-complete-payload'
```

Inno Setup 6.7 以降でビルドします。テストでは、生成されたサンプルと分離された一時ライブラリを使用します。これらは、読み取り、選択、連続ページ、OCR、辞書、注釈、エクスポート、複数ファイルの結合、および言語設定をカバーします。インストーラー ペイロードには言語カタログが含まれますが、`data`、`exports`、`.git`、およびテスト アーティファクトは含まれません。
