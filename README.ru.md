# XT 阅迹 · XT-ReadTrace

Настольный инструмент XT (XuTao) для чтения PDF-файлов на английском языке, сбора словарного запаса и создания исследовательских заметок. Прочитай страницу, оставь след.

## Установить и запустить

Загрузите XT-ReadTrace-1.13.0-Setup-x64.exe с [Releases](https://github.com/peekabooXT/XT-ReadTrace/releases), затем запустите установщик. Он включает в себя полный автономный словарь, данные оптического распознавания текста на английском языке и среду выполнения. Оставьте опцию ярлыка на рабочем столе включенной. Для установленного приложения не требуется установка Python или учетная запись.

Папка установки по умолчанию — `D:\tools\codex\XT-ReadTrace`. Откройте ярлык на рабочем столе с именем XT 阅迹 или запустите `XT阅迹.exe`. Сохраните папки `_internal` и `dictionary` рядом с исполняемым файлом.

## Язык интерфейса

Английский используется по умолчанию. Откройте «Настройки», выберите «Язык интерфейса» и сохраните. Интерфейс мгновенно переключается и запоминает ваш выбор для будущих запусков. Доступные языки: китайский, английский, немецкий, японский, французский, корейский, итальянский, хинди, испанский, современный стандартный арабский, португальский и русский. В арабском языке используется интерфейс с письмом справа налево.

Выбор языка применяется к инструментам чтения, настройкам, диалоговым окнам, параметрам экспорта, справке, сообщениям о состоянии и ошибкам. Он не переводит исходный PDF-файл, собранные английские термины или ваши личные определения. Входящий в комплект словарь содержит англо-китайские значения. Все языковые ресурсы и шрифты Noto с открытой лицензией для японского, корейского, арабского и хинди включены для автономного использования.

## Читайте, собирайте и комментируйте

1. Импортируйте один или несколько PDF-файлов на английском языке или перетащите их в окно. Поддерживаются текстовые PDF-файлы и отсканированные PDF-файлы.
2. Дважды щелкните слово, чтобы собрать его; дважды щелкните его цветное жирное подчеркивание еще раз, чтобы удалить это вхождение. Нажмите или перетащите, чтобы выбрать фразу, проверьте текст ниже, затем нажмите Enter, чтобы собрать его.
3. Постоянно прокручивайте страницы. Выберите непрерывный просмотр отдельных страниц или просмотр двух страниц, отрегулируйте масштаб, перейдите на страницу или выполните поиск в PDF-файле.
4. Для чтения аннотаций используйте выделение текста, подчеркивание текста, ручку от руки, прямоугольник или текстовую заметку. Заметки появляются прямо на странице, поддерживают несколько строк и могут редактироваться двойным щелчком мыши в режиме «Выбор/Чтение». Используйте ластик, менеджер аннотаций, отмените или повторите действия, чтобы изменить аннотации.
5. По умолчанию для семи ярлыков инструментов используются номера 1–7, и их можно изменить в настройках. Ярлыки не переключают инструменты, пока вы вводите текст в редактируемое поле.

Для сканирования сначала запустите OCR на текущей странице. Приложение использует связанные данные OCR на английском языке. Проверяйте результаты распознавания, особенно в сложных столбцах, таблицах, формулах или некачественных сканах.

## Офлайн-словарь и личные значения

Включенный словарь ECDICT содержит 770 611 статей. Выберите слово или введите запрос, чтобы увидеть его значение, произношение и возможные основные формы. Если фраза отсутствует, приложение четко указывает определения ее составляющих слов.

Используйте «Редактировать/Добавить значение», чтобы сохранить собственное объяснение и необязательное произношение. Личные значения распределяются между PDF-файлами, выдерживают перезапуск и имеют приоритет при поиске и экспорте словарных таблиц. Включенный словарь остается доступным только для чтения. Восстановление словарного значения требует подтверждения.

## Экспортируйте один PDF-файл или объедините несколько словарей

- Wordbook TXT: экспорт текста UTF-8, совместимого с облачным словарем MAiMemo. В режиме главы в каждой строке сохраняется одно полное слово или фраза с сохранением регистра. Также доступны главы страниц, обычный текст и режим базовой формы `//`. Обработку базовой формы выполняет MAiMemo.
- Несколько PDF-файлов: нажмите «Объединить словари» под списком документов, проверьте файлы и просмотрите результат. При необходимости выберите все или снимите выделение. Удалите дубликаты в файлах, при необходимости преобразуйте их в нижний регистр и экспортируйте один словарь TXT. TXT может группировать записи по файлам, по файлам и страницам или в одну главу.
- Распечатанная словарная таблица: экспортируйте PDF-файл формата A4 с английскими словами или фразами слева и значениями справа. Предварительный просмотр и редактирование значений для этого экспорта. Длинные значения продолжаются на последующих страницах с повторяющимися заголовками столбцов. Объединенная таблица может включать все проверенные PDF-файлы и использовать сохраненные вами личные значения.
- Слова и аннотации PDF: создайте копию, содержащую стили из собранных слов и стандартные аннотации PDF. Текстовые заметки остаются видимыми и пригодными для печати. Исходный PDF-файл сохраняется.
- Чтение PDF с пространством для письма: добавьте одну или две пустые строки между строками визуального текста для рукописных заметок. Выберите все страницы, текущую страницу или диапазон страниц. В выводе используется нумерация страниц формата A4 и может включаться оформление собранных слов. Обработка выполняется в фоновом режиме и может быть отменена.

При слиянии выбранные записи считываются без изменения их PDF-файлов, пометок, примечаний или позиции чтения. Словарь содержит собранные термины; основные моменты чтения и другие аннотации экспортируются отдельно в PDF-файл с аннотациями.

## Персональные данные и обновления

Приложение хранит ваши PDF-файлы, словарный запас, заметки, предпочтения и личные значения в своей локальной папке `data`. Экспортированные файлы обычно сохраняются в `exports`. Закройте приложение и создайте резервную копию обеих папок при переходе на другой компьютер.

Обновления установщика сохраняют существующие персональные данные. При удалении удаляются программные файлы и ярлыки, оставляя личные данные. Исходные версии и первоначальные установщики исключают личные PDF-файлы, библиотечные записи, пароли и файлы экспорта. Пароли открытия PDF-файлов хранятся в памяти и не сохраняются на диск.

## Запуск из исходного кода

Используйте автономный CPython 3.12 или новее. Рекомендуется использовать изолированную среду, чтобы избежать конфликтов Qt DLL с Anaconda. Для установки зависимостей Python может потребоваться доступ к Интернету; словарь поставляется в комплекте и может быть подготовлен в автономном режиме.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\src\requirements.txt
.\src\prepare_dictionary.ps1 -Python .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe .\src\app.py
```

`dictionary/ecdict.sqlite.gz` содержит полный словарь. Сценарий подготовки проверяет контрольные суммы и распаковывает их локально. Установщики Windows включают распакованную базу данных. Источник словаря и информация о контрольной сумме находятся в `dictionary/source.json`; его лицензия MIT находится в `dictionary/LICENSE.txt`.

## Создайте и проверьте

```powershell
.\src\build.ps1 -Python python
.\tests\run_checks.ps1 -Python .\.venv\Scripts\python.exe
.\installer\build-installer.ps1 -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -Payload 'path-to-complete-payload'
```

Сборка с помощью Inno Setup 6.7 или новее. В тестах используются сгенерированные образцы и изолированные временные библиотеки. Они охватывают чтение, выбор, непрерывные страницы, распознавание текста, словари, аннотации, экспорт, объединение нескольких файлов и языковые настройки. Полезные нагрузки установщика включают языковые каталоги и исключают `data`, `exports`, `.git` и тестовые артефакты.
