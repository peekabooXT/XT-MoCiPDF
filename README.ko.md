영어 PDF를 읽고, 어휘를 수집하고, 연구 노트를 작성하기 위한 XT (XuTao)의 데스크톱 도구입니다. 페이지를 읽고 흔적을 남겨보세요.

## 설치 및 실행

[Releases](https://github.com/peekabooXT/XT-ReadTrace/releases)에서 XT-ReadTrace-1.13.1-Setup-x64.exe를 다운로드한 다음 설치 프로그램을 실행합니다. 여기에는 완전한 오프라인 사전, 영어 OCR 데이터 및 런타임이 포함됩니다. 바탕 화면 바로 가기 옵션을 활성화된 상태로 유지하세요. 설치된 앱에는 Python 설치나 계정이 필요하지 않습니다.

기본 설치 폴더는 `D:\tools\codex\XT-ReadTrace`입니다. XT 阅迹라는 바탕 화면 바로 가기를 열거나 `XT阅迹.exe`를 실행합니다. 실행 파일과 함께 `_internal` 및 `dictionary` 폴더를 유지하십시오.

## 인터페이스 언어

영어가 기본값입니다. 설정을 열고 인터페이스 언어를 선택한 후 저장하세요. 인터페이스는 즉시 전환되며 향후 실행을 위해 사용자의 선택을 기억합니다. 사용 가능한 언어: 중국어, 영어, 독일어, 일본어, 프랑스어, 한국어, 이탈리아어, 힌디어, 스페인어, 현대 표준 아랍어, 포르투갈어, 러시아어. 아랍어는 오른쪽에서 왼쪽으로 쓰는 인터페이스를 사용합니다.

언어 선택은 읽기 도구, 설정, 대화 상자, 내보내기 옵션, 도움말, 상태 메시지 및 오류에 적용됩니다. 원본 PDF, 수집된 영어 용어 또는 개인 정의는 번역되지 않습니다. 번들 사전은 영어-중국어 의미를 제공합니다. 일본어, 한국어, 아랍어, 힌디어의 모든 언어 리소스와 오픈 라이센스 Noto 글꼴이 오프라인 사용을 위해 포함되어 있습니다.

## 읽고, 수집하고, 주석을 답니다.

1. 하나 이상의 영어 PDF를 가져오거나 창으로 끌어다 놓습니다. 텍스트 PDF와 스캔한 PDF가 지원됩니다.
2. 단어를 두 번 클릭하면 수집됩니다. 해당 항목을 제거하려면 색칠된 굵은 밑줄을 다시 두 번 클릭합니다. 클릭하거나 드래그하여 문구를 선택하고, 아래 텍스트를 확인한 후 Enter를 눌러 수집하세요.
3. 페이지 전체를 계속해서 스크롤합니다. 연속된 단일 페이지 또는 두 페이지 보기를 선택하고, 확대/축소를 조정하고, 페이지로 이동하거나 PDF를 검색하세요.
4. 주석을 읽으려면 텍스트 강조 표시, 텍스트 밑줄, 자유형 펜, 직사각형 또는 텍스트 메모를 사용하십시오. 메모는 페이지에 직접 표시되고 여러 줄을 지원하며 선택/읽기 모드에서 두 번 클릭하여 편집할 수 있습니다. 주석을 수정하려면 지우개, 주석 관리자, 실행 취소 또는 다시 실행을 사용하세요.
5. 7개의 도구 단축키는 기본적으로 1~7로 설정되어 있으며 설정에서 변경할 수 있습니다. 편집 가능한 필드에 입력하는 동안 단축키는 도구를 전환하지 않습니다.

스캔하려면 먼저 현재 페이지에서 OCR을 실행하세요. 이 앱은 번들로 제공되는 영어 OCR 데이터를 사용합니다. 특히 복잡한 열, 표, 수식 또는 품질이 낮은 스캔에서 인식 결과를 확인하세요.

## 오프라인 사전과 개인적인 의미

포함된 ECDICT 사전에는 770,611개의 항목이 포함되어 있습니다. 단어를 선택하거나 쿼리를 입력하여 단어의 의미, 발음 및 가능한 기본 형태를 확인하세요. 문구가 누락된 경우 앱은 해당 구성 단어 정의에 명확하게 라벨을 지정합니다.

편집/의미 추가를 사용하여 자신만의 설명과 선택적 발음을 저장하세요. 개인적인 의미는 PDF 전체에서 공유되고, 다시 시작해도 유지되며, 조회 및 어휘표 내보내기에서 우선순위를 갖습니다. 번들 사전은 읽기 전용으로 유지됩니다. 사전적 의미를 복원하려면 확인이 필요합니다.

## 하나의 PDF를 내보내거나 여러 단어장을 병합하세요.

- 단어장 TXT: MAiMemo의 클라우드 단어장과 호환되는 UTF-8 텍스트를 내보냅니다. 장 모드는 한 줄에 하나의 완전한 단어 또는 구문을 유지하고 대소문자를 유지합니다. 페이지 장, 일반 텍스트 및 `//` 기본 형식 모드도 사용할 수 있습니다. 기본 형식 처리는 MAiMemo에 의해 수행됩니다.
- 여러 PDF: 문서 목록 아래 단어장 병합을 클릭하고 파일을 확인한 후 결과를 미리 봅니다. 필요에 따라 모두 선택하거나 선택을 취소합니다. 파일 전체에서 중복된 항목을 제거하고, 선택적으로 소문자로 변환하고, 단일 TXT 단어장을 내보냅니다. TXT는 항목을 파일별로, 파일 및 페이지별로 그룹화하거나 하나의 장으로 그룹화할 수 있습니다.
- 인쇄 가능한 어휘표: 왼쪽에는 영어 단어 또는 구문, 오른쪽에는 의미가 포함된 A4 PDF를 내보냅니다. 이 내보내기의 의미를 미리 보고 편집하세요. 긴 의미는 반복되는 열 헤더와 함께 다음 페이지로 계속됩니다. 병합된 테이블에는 확인된 모든 PDF가 포함될 수 있으며 저장된 개인 의미를 사용합니다.
- 단어 및 주석 PDF: 수집된 단어 스타일과 표준 PDF 주석이 포함된 사본을 만듭니다. 텍스트 메모는 직접 표시되고 인쇄 가능한 상태로 유지됩니다. 원본 PDF는 보존됩니다.
- 쓰기 공간이 있는 PDF 읽기: 손으로 쓴 메모를 위해 시각적 텍스트 행 사이에 빈 줄 1~2개를 추가합니다. 모든 페이지, 현재 페이지 또는 페이지 범위를 선택합니다. 출력은 A4 페이지 매김을 사용하며 수집된 단어 스타일을 포함할 수 있습니다. 처리는 백그라운드에서 실행되며 취소될 수 있습니다.

병합은 PDF, 표시, 메모 또는 읽기 위치를 변경하지 않고 선택한 레코드를 읽습니다. 단어장에는 수집된 용어가 포함되어 있습니다. 읽기 하이라이트 및 기타 주석은 주석이 달린 PDF에서 별도로 내보내집니다.

## 개인 데이터 및 업그레이드

이 앱은 PDF, 어휘, 메모, 기본 설정 및 개인적인 의미를 로컬 `data` 폴더에 저장합니다. 내보낸 파일은 일반적으로 `exports`에 저장됩니다. 다른 컴퓨터로 이동할 때는 앱을 닫고 두 폴더를 모두 백업하세요.

설치 프로그램 업그레이드는 기존 개인 데이터를 보존합니다. 제거하면 개인 데이터는 그대로 두고 프로그램 파일과 바로가기가 제거됩니다. 소스 릴리스 및 초기 설치 프로그램은 개인 PDF, 라이브러리 기록, 비밀번호 및 내보내기 파일을 제외합니다. PDF 열기 비밀번호는 메모리에 보관되며 디스크에 저장되지 않습니다.

## 소스에서 실행

독립형 CPython 3.12 이상을 사용하세요. Anaconda와의 Qt DLL 충돌을 방지하려면 격리된 환경을 권장합니다. Python 종속성을 설치하려면 인터넷 액세스가 필요할 수 있습니다. 사전은 번들로 제공되며 오프라인으로 준비할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\src\requirements.txt
.\src\prepare_dictionary.ps1 -Python .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe .\src\app.py
```

`dictionary/ecdict.sqlite.gz`에는 전체 사전이 포함되어 있습니다. 준비 스크립트는 체크섬을 확인하고 로컬에서 압축을 풉니다. Windows 설치 프로그램에는 압축이 풀린 데이터베이스가 포함되어 있습니다. 사전 소스 및 체크섬 정보는 `dictionary/source.json`에 있습니다. MIT 라이센스는 `dictionary/LICENSE.txt`에 있습니다.

## 빌드 및 확인

```powershell
.\src\build.ps1 -Python python
.\tests\run_checks.ps1 -Python .\.venv\Scripts\python.exe
.\installer\build-installer.ps1 -ISCC 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe' -Payload 'path-to-complete-payload'
```

Inno Setup 6.7 이상으로 빌드하세요. 테스트에서는 생성된 샘플과 격리된 임시 라이브러리를 사용합니다. 읽기, 선택, 연속 페이지, OCR, 사전, 주석, 내보내기, 다중 파일 병합 및 언어 기본 설정을 다룹니다. 설치 프로그램 페이로드에는 언어 카탈로그가 포함되며 `data`, `exports`, `.git` 및 테스트 아티팩트는 제외됩니다.

## 범위 및 번역

이 앱은 독립적으로 개발되었으며 공식 MAiMemo 제품이 아닙니다. MAiMemo에 로그인하거나 단어장을 자동으로 업로드하지 않습니다. 오프라인 조회는 전체 문장 기계 번역이 아닙니다. OCR, 일반적이지 않은 어휘 및 복잡한 PDF 레이아웃에는 확인이 필요할 수 있습니다.

번역된 인터페이스 텍스트와 README는 자동화된 지원을 통해 준비되었습니다. 위의 연락처 주소로 수정을 환영합니다. 영어 README는 문서 기준입니다. 코드 식별자, 안정적인 파일 이름 및 저장된 기록 키는 일관된 프로젝트 이름을 사용합니다. [Naming conventions](NAMING.md)를 참조하세요.

1.13.1: 자유 펜: Ctrl을 누르면 직선, Shift를 누르면 물결선을 그립니다. 마우스 왼쪽 버튼을 누른 채 드래그하여 주석을 지웁니다. 수집한 단어 표시는 선택 / 읽기 모드에서 더블 클릭하여 취소합니다.
